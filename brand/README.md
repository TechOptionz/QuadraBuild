## The mark

An isometric "Q-House" built from four blocks, one per division:

- **Roof** in brick: Quadra Renovations
- **Left wall** in sage: Quadra Commercial
- **Right wall + diagonal tail** in slate: Quadra Homes. The tail turns the house outline into a **Q**.
- **Base + window** in sandstone: Quadra Approvals

Each block has a front face plus a darker extruded edge, which gives it depth.

## Wordmark

- **Font:** Archivo (Google Fonts) at width 112%, uppercase, letter-spacing 0.08em.
- **QUADRA** is Bold (700). **BUILD** is Medium (500) at 72% opacity.
- Set on one line, with the mark at about 2.3× the cap height and a gap of about 0.6× the cap height.
- **Body font on the site:** Instrument Sans.

## Notes from the brand audit (Oct 2026)

- At very small sizes (favicon, 16–24px) the shaded edges get muddy. A flat or one-colour version would help there.
- Ideas worth exploring:
  - Division lockups such as "QUADRA | Renovations", with the divider in that division's colour
  - One-colour versions in ink and paper for signage
  - A favicon-specific simplification
- Keep the diagonal Q tail. It's what makes the house read as a Q.
